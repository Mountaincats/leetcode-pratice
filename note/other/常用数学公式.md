### 一、上下界函数
**1. 核心转换公式**
- 对于任意实数 $x$ 有：
$$\lceil x \rceil = -\lfloor -x \rfloor$$
$$\lfloor x \rfloor = -\lceil -x \rceil$$

    > 这个关系的本质是：**对一个数向上取整，等价于先将其取相反数，向下取整，再取相反数。**
    > 
    > - **`floor`**：朝着 **负无穷** 的方向取整。
    > - **`ceil`**：朝着 **正无穷** 的方向取整。
    > - 取负号（`-`）会翻转数轴的方向，因此也将“取整方向”从正无穷翻转为负无穷，反之亦然。

- 对于正整数除法向上取整有：
$$
\left\lceil \frac{a}{b} \right\rceil = \left\lfloor \frac{a + b - 1}{b} \right\rfloor
$$

    > 设 $a$ 除以 $b$ 的商为 $k$，余数为 $r$。根据整数除法的定义：
    > $$a = kb + r \quad (0 \le r < b)$$
    > 
    > 需要证明：
    > $$\left\lceil \frac{kb+r}{b} \right\rceil = \left\lfloor \frac{kb+r + b - 1}{b} \right\rfloor$$
    > 
    > **左边：**
    > $$\left\lceil k + \frac{r}{b} \right\rceil = k + \left\lceil \frac{r}{b} \right\rceil$$
    > 由于 $0 \le r < b$：
    > -   若 $r = 0$，$\left\lceil \frac{r}{b} \right\rceil = 0$，结果为 $k$。
    > -   若 $r > 0$，$\left\lceil \frac{r}{b} \right\rceil = 1$，结果为 $k+1$。
    > 
    > **右边：**
    > $$\left\lfloor \frac{kb+r + b - 1}{b} \right\rfloor = \left\lfloor k + 1 + \frac{r-1}{b} \right\rfloor = k + 1 + \left\lfloor \frac{r-1}{b} \right\rfloor$$
    > 由于 $0 \le r < b$，则 $-1 \le r-1 < b-1$：
    > -   若 $r = 0$，$\frac{r-1}{b} = -\frac{1}{b}$，$\left\lfloor -\frac{1}{b} \right\rfloor = -1$，结果为 $k+1-1 = k$。
    > -   若 $r > 0$，$-1 < \frac{r-1}{b} < 1$，$\left\lfloor \frac{r-1}{b} \right\rfloor = 0$，结果为 $k+1$。
    > 
    > 左右两边结果完全一致，得证。

**2. 其他重要关系**
- **与自身的关系**：
    $$\lceil x \rceil = \lfloor x \rfloor \quad \text{当且仅当 } x \text{ 是整数}$$

- **差值关系**：
    $$\lceil x \rceil - \lfloor x \rfloor = \begin{cases} 0 & \text{if } x \in \mathbb{Z} \\ 1 & \text{if } x \notin \mathbb{Z} \end{cases}$$
    即，对于非整数，向上取整的结果总是比向下取整大 1。

- **与整数部分的关系**：
    对于任意实数 $x$，可以表示为 $x = n + r$，其中 $n$ 是整数，$0 \leq r < 1$。
    - $\lfloor x \rfloor = n$
    - $\lceil x \rceil = \begin{cases} n & \text{if } r = 0 \\ n+1 & \text{if } r > 0 \end{cases}$

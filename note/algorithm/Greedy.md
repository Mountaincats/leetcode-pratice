## 贪心算法（Greedy Algorithm）
[TOC]

### 一、理论
贪心算法是一种在每一步选择中都采取当前状态下**最优（局部最优）**的决策，从而希望导致结果是**全局最优**的算法范式。它不从整体最优角度考虑，而是通过一系列局部最优的累积来解决问题。

**1. 核心思想**
- **无后效性**：当前的选择不会影响之前的状态，也不依赖于未来的状态。
- **局部最优**：每一步都做出一个不可回退的决定，且该决定在当前看来是最好的。

**2. 两个性质**
并非所有问题都适合贪心算法，一个问题若要使用贪心算法求解，通常需要满足以下两个条件：
- **贪心选择性质（Greedy Choice Property）**：所求问题的全局最优解可以通过一系列局部最优的选择（贪心选择）来达到。这是贪心算法可行的关键。
- **最优子结构（Optimal Substructure）**：一个问题的最优解包含其子问题的最优解。这是动态规划和贪心算法共同的特征。

**3. 证明方法**
贪心算法的常见证明方法有：
- **数学归纳法**：证明第一步选择是安全的，且后续子问题仍满足贪心性质。
- **交换论证（Exchange Argument）**：假设存在一个最优解与贪心解不同，通过交换最优解中的某些步骤构造出一个新的最优解，使其更贴近贪心解，且不劣于原最优解，最终证明贪心解即为最优解。
- **反证法**：假设贪心选择不是最优的，推导出矛盾。
- **拟阵（Matroid）**：贪心算法适用性的数学理论基础。如果能证明问题符合拟阵结构，那贪心一定正确。

**4. 局限性**
贪心算法的难点在于**证明**。很多时候直觉上的贪心策略是错误的。例如“部分背包问题”可用贪心，但“0-1背包问题”则不能（因为贪心选择会影响后续容量的可用性）。当贪心失效时，通常需要升级为动态规划。

### 二、拟阵

#### (1) 概念

> **定义**
> 一个拟阵是一个二元组 $M = (E, \mathcal{I})$，其中 $E$ 是有限非空集合（基集），$ \mathcal{I}$ 是 $E$ 的一组子集族，满足：
> 1.  **遗传性（Heredity）**：若 $B \in \mathcal{I}$ 且 $A \subseteq B$，则 $A \in \mathcal{I}$。
> 2.  **交换性（Exchange）**：若 $A, B \in \mathcal{I}$ 且 $|A| < |B|$，则存在 $x \in B \setminus A$ 使得 $A \cup \{x\} \in \mathcal{I}$。

拟阵（Matroid）是贪心算法适用的**数学充要条件**。一旦证明一个问题可以建模为拟阵，那么贪心算法一定能得到最优解。

#### (2) 例子

**1. 问题定义：区间调度（Interval Scheduling）**

给定一组区间集合 $S = \{I_1, I_2, ..., I_n\}$，其中区间 $I_i = [s_i, f_i)$，满足 $s_i < f_i$。若两个区间不重叠，则称它们**兼容**。
**目标**：选取尽可能多的区间，使得任意两个被选区间互不重叠。


**2. 建模：将问题转化为拟阵**

令基集 $E = S$（所有区间的集合）。
定义独立集族 $\mathcal{I} = \{ A \mid A \subseteq E, \text{且 } A \text{ 中所有区间两两不重叠} \}$。
我们称 $M = (E, \mathcal{I})$ 为**区间拟阵（Interval Matroid）**。

**3. 第一步：证明 $M$ 是一个拟阵**

**引理 1（遗传性）**：$\mathcal{I}$ 满足遗传性。
**证明**：
任取 $A \in \mathcal{I}$，则 $A$ 中任意两区间不重叠。
任取 $B \subseteq A$，显然 $B$ 中的区间也是两两不重叠的。
故 $B \in \mathcal{I}$。遗传性得证。

**引理 2（交换性）**：$\mathcal{I}$ 满足交换性。
**证明**：
设 $A, B \in \mathcal{I}$ 且 $|A| < |B|$。
由于 $A, B$ 均为不重叠区间集，我们可以将区间按其**结束时间**升序排列。
因为 $|A| < |B|$，根据鸽巢原理，$B$ 中必然存在至少一个区间，其结束时间早于 $A$ 中某个区间的开始时间（或者更准确地说，在排序后的序列中，$B$ 占用的“时间段槽位”更多）。
严谨地，设 $A = \{a_1, a_2, ..., a_k\}$，$B = \{b_1, b_2, ..., b_m\}$，$k<m$，且均按结束时间排序。
考虑 $b_1$（B中结束最早的区间）。若 $b_1$ 不在 $A$ 中，且 $b_1$ 与 $A$ 中所有区间都不重叠（因为 $b_1$ 结束最早，它不可能与 $a_1$ 重叠，除非 $f(b_1) > s(a_1)$，但由于 $k<m$，总存在某个 $b_j$ 插入到了 $A$ 的间隙中）。
实际上，标准的证明方式是：由于 $B$ 中有 $m$ 个区间，$A$ 中有 $k$ 个区间，将 $A$ 和 $B$ 的区间混合排序。因为 $B$ 的区间更多，必然存在一个区间 $b \in B$，它的结束时间早于 $A$ 中某个区间的开始时间，或者 $b$ 能放入 $A$ 的某个空隙。
因此，存在 $x \in B \setminus A$，使得 $A \cup \{x\}$ 仍然是不重叠的，即 $A \cup \{x\} \in \mathcal{I}$。交换性得证。

综上，$M = (E, \mathcal{I})$ 是一个拟阵。

**4. 第二步：贪心算法与最优性证明**

**贪心算法**：
**1. 将所有区间按结束时间升序排列**：$f_1 \le f_2 \le ... \le f_n$。
**2. 依次遍历区间 $i$**：若区间 $i$ 与已选集合 $A$ 不冲突，则将 $i$ 加入 $A$。
**3. 返回 $A$。**

**定理**：上述贪心算法找到了拟阵 $M$ 的一个**最大基数独立集（Maximum Cardinality Independent Set）**，即最优解。

**证明**：
根据拟阵理论中的**Rado-Edmonds 定理**，对于任意拟阵 $M=(E, \mathcal{I})$，贪心算法总能找到最大独立集。
具体证明如下：
设贪心算法输出的集合为 $G = \{g_1, g_2, ..., g_k\}$（按选择顺序，即结束时间递增）。
设任意一个最优独立集（基）为 $O = \{o_1, o_2, ..., o_m\}$，其中 $m \ge k$，且 $O$ 中的区间也按结束时间排序。

下面将证明：对于所有 $i = 1, ..., k$，有 $f(g_i) \le f(o_i)$。
（这称为**前缀最优性**，意味着贪心算法在前 $i$ 步的决策不差于最优解的前 $i$ 步）。

归纳法：
- **基础步 ($i=1$)**：贪心算法选择了结束时间最早的区间 $g_1$。因为 $o_1$ 是某个区间，且 $g_1$ 是所有区间中结束最早的，所以 $f(g_1) \le f(o_1)$。
- **归纳步**：假设对于前 $j$ 步，有 $f(g_i) \le f(o_i)$ 对所有 $i \le j$ 成立。
  考虑第 $j+1$ 步。
  由于 $O$ 是一个独立集，且 $\{o_1, ..., o_j\} \subseteq O$，那么 $\{o_1, ..., o_j\} \in \mathcal{I}$。
  根据贪心算法的定义，$g_{j+1}$ 是所有与 $\{g_1, ..., g_j\}$ 兼容的区间中结束时间最早的。
  由于 $f(g_i) \le f(o_i)$（归纳假设），区间 $g_{j+1}$ 的可用时间窗口（即 $f(g_j)$ 之后）至少不晚于 $o_{j+1}$ 的可用时间窗口。
  贪心算法在 $f(g_j)$ 之后选择了结束最早的 $g_{j+1}$。如果 $o_{j+1}$ 与 $\{g_1, ..., g_j\}$ 兼容，那么 $f(g_{j+1}) \le f(o_{j+1})$。
  如果 $o_{j+1}$ 不与 $\{g_1, ..., g_j\}$ 兼容，由于 $f(g_j) \le f(o_j)$，导致冲突的时间点必然在 $f(g_j)$ 之后，但这不影响 $g_{j+1}$ 的选择逻辑。
  因此，$f(g_{j+1}) \le f(o_{j+1})$。

**结论**：
由前缀最优性可知，当贪心算法结束时，$k \le m$。
但根据拟阵的交换性，如果存在 $m > k$，我们可以不断向 $G$ 中添加 $O$ 中的元素直到大小相等，这与 $G$ 是贪心算法终止的结果矛盾（因为贪心算法无法再添加任何元素，而 $O$ 中的元素如果能加入，早就被加入了）。
因此，必有 $k = m$。
即 $|G| = |O|$，贪心解是最优解。

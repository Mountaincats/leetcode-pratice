## Knuth-Morris-Pratt(KMP) 字符串匹配算法
同类算法还有 Boyer-Moore 算法、Sunday 算法、Rabin-Karp 算法。

---

### 一、前缀函数

#### (1) 概念
对于长度为 **$m$** 的字符串 **$s$**，其前缀函数 **$\pi(i)(0≤i<m)$** 表示 **$s$** 的子串 **$s[0:i]$** 的最长的相等的真前缀与真后缀的长度。特别地，如果不存在符合条件的前后缀，那么 **$\pi(i)=0$**。其中真前缀与真后缀的定义为不等于自身的的前缀与后缀。

> **示例**
> 字符串 aabaaab 的前缀函数值依次为 0, 1, 0, 1, 2, 2, 3

#### (2) 性质
**1. 前缀函数对应的字符串相等关系**

若 $\pi(i)=k$，则

**\[
s[0..k-1]=s[i-k+1..i].
\]**

这是前缀函数定义的直接结果：长度为 $k$ 的前缀，同时也是 $s[0..i]$ 的后缀。

如果 $k>0$，将两侧的最后一个字符去掉，还可得到

**\[
s[0..k-2]=s[i-k+1..i-1].
\]**

这说明如果长度为 $k$ 的字符串是 $s[0..i]$ 的相等前后缀，那么长度为 $k-1$ 的字符串就是 $s[0..i-1]$ 的相等前后缀。

**2. $\pi(i)\leq \pi(i-1)+1$**

设

**\[
\pi(i)=k.
\]**

根据定义，有

**\[
s[0..k-1]=s[i-k+1..i].
\]**

删除两侧最后一个字符，得到

**\[
s[0..k-2]=s[i-k+1..i-1].
\]**

因此，长度为 $k-1$ 的字符串是 $s[0..i-1]$ 的相等真前缀与真后缀。由于 $\pi(i-1)$ 是其中最长者，所以

**\[
\pi(i-1)\geq k-1.
\]**

即

**\[
\pi(i)\leq \pi(i-1)+1.
\]**

因此，相邻两个前缀函数值之间，最多只能增加 $1$，但可以一次减少很多。

**3. 如果 $s[i]=s[\pi(i-1)]$，则 $\pi(i)=\pi(i-1)+1$**

设

**\[
j=\pi(i-1).
\]**

根据前缀函数定义，

**\[
s[0..j-1]=s[i-j..i-1].
\]**

又因为

**\[
s[j]=s[i],
\]**

所以可以在上述两个相等字符串的末尾分别添加 $s[j]$ 和 $s[i]$，得到

**\[
s[0..j]=s[i-j..i].
\]**

因此，$s[0..i]$ 至少存在一个长度为 $j+1$ 的相等前后缀，即

**\[
\pi(i)\geq j+1.
\]**

另一方面，根据性质二，

**\[
\pi(i)\leq\pi(i-1)+1=j+1.
\]**

两式结合可得

**\[
\pi(i)=j+1=\pi(i-1)+1.
\]**

**4. 失配时为什么可以令 $j=\pi(j-1)$**

计算 $\pi(i)$ 时，假设当前已经知道长度为 $j$ 的字符串是 $s[0..i-1]$ 的后缀，即

**\[
s[0..j-1]=s[i-j..i-1].
\]**

接下来尝试比较 $s[i]$ 和 $s[j]$。

如果

**\[
s[i]\neq s[j],
\]**

那么长度为 $j+1$ 的前后缀无法形成，需要寻找一个小于 $j$ 的候选长度。

假设 $k<j$ 是一个仍有可能扩展的候选长度，那么长度为 $k$ 的字符串必须既是：

- $s[0..j-1]$ 的前缀；
- $s[0..j-1]$ 的后缀。

原因是 $s[0..j-1]$ 本身等于 $s[0..i-1]$ 的长度为 $j$ 的后缀。若长度 $k$ 仍能作为 $s[0..i-1]$ 的前后缀，那么它也必然是 $s[0..j-1]$ 的前后缀。

因此，下一个最大的可能长度正是

**\[
\pi(j-1).
\]**

于是可以令

**\[
j\leftarrow\pi(j-1)
\]**

继续比较，而不需要逐个尝试 $j-1,j-2,\dots$。

不断执行该操作，就会依次枚举当前字符串所有可能的相等前后缀长度：

**\[
j,\ \pi(j-1),\ \pi\bigl(\pi(j-1)-1\bigr),\dots
\]**

这就是前缀函数算法能够快速“回退”的核心原因。


#### (3) 求解
前缀函数可以通过递推的方式在线性时间内计算得出。假设我们已经计算出 $\pi(0), \pi(1), \dots, \pi(i-1)$，现在需要计算 $\pi(i)$。

**步骤：**
- 初始令 $j = \pi(i-1)$，即上一个位置的最长相等前后缀长度。
- 如果 $s[i] = s[j]$，则 $\pi(i) = j + 1$，计算结束。
- 否则，令 $j = \pi(j-1)$，回退到更短的候选前后缀，重复步骤2。
- 当 $j = 0$ 时，如果 $s[i] = s[0]$，则 $\pi(i) = 1$，否则 $\pi(i) = 0$。

> 每次不相等，前缀末尾向左靠，后缀开头向右靠

**示例演示：**
以字符串 "aabaaab" 为例，逐步计算前缀函数：

| i | s[i] | j(初始) | 比较过程 | $\pi$(i) |
|---|------|---------|----------|------|
| 0 | a | - | - | 0 |
| 1 | a | j=$\pi$(0)=0 | s[1]=a, s[0]=a, 相等 | 1 |
| 2 | b | j=$\pi$(1)=1 | s[2]=b, s[1]=a, 不等->j=$\pi$(0)=0; s[2]=b, s[0]=a, 不等 | 0 |
| 3 | a | j=$\pi$(2)=0 | s[3]=a, s[0]=a, 相等 | 1 |
| 4 | a | j=$\pi$(3)=1 | s[4]=a, s[1]=a, 相等 | 2 |
| 5 | a | j=$\pi$(4)=2 | s[5]=a, s[2]=b, 不等->j=$\pi$(1)=1; s[5]=a, s[1]=a, 相等 | 2 |
| 6 | b | j=$\pi$(5)=2 | s[6]=b, s[2]=b, 相等 | 3 |

最终得到前缀函数值序列：$\pi = [0, 1, 0, 1, 2, 2, 3]$

#### (4) 求解时间复杂度证明
在算法中，变量 **$j$** 只会发生两类变化：

- 当字符匹配时，执行 **$j \leftarrow j+1$**；
- 当字符失配时，执行 **$j \leftarrow \pi(j-1)$**，并且一定有

  **\[
  \pi(j-1) < j,
  \]**

  所以 **$j$ 至少减少 $1$**。

由于

**\[
\pi(i) \leq \pi(i-1)+1,
\]**

随着外层循环从左向右执行，**$j$** 每处理一个字符最多增加 **$1$**。整个算法一共处理 **$m$** 个字符，因此 **$j$** 的总增加量不超过 **$m-1$**。

同时，**$j$** 始终满足

**\[
j \geq 0.
\]**

因此，**$j$** 的总减少量不可能超过“初始值加上总增加量”。初始时 **$j=0$**，所以整个算法中 **$j$** 的总减少量也是 **$O(m)$**。

而 `while` 循环每执行一次，都会使 $j$ 至少减少 $1$。因此：

- 所有 `while` 循环的总执行次数为 **$O(m)$**；
- 外层循环执行 **$m-1$** 次；
- 每次外层循环除 `while` 外只进行常数次操作。

所以前缀函数算法的总时间复杂度为

**\[
\boxed{O(m)}.
\]**

> 同理可用该方法证明匹配过程的时间复杂度为 **$O(n)$**，最终整个 KMP 算法的时间复杂度为 **$O(n + m)$**。

#### (5) 求解正确性证明

计算 $\pi(i)$ 时，初始令

**\[
j=\pi(i-1).
\]**

此时 **$j$** 是 **$s[0..i-1]$** 的最长相等前后缀长度，因此它是扩展到位置 **$i$** 时最大的候选。

算法保持以下不变式：

> 每次比较 **$s[i]$** 与 **$s[j]$** 之前，长度为 **$j$** 的字符串都是 **$s[0..i-1]$** 的相等前后缀，并且所有大于 **$j$** 的候选长度都已经被排除。

分情况讨论：

- 如果 **$s[i]=s[j]$**，那么长度为 **$j$** 的相等前后缀可以扩展为长度 **$j+1$**，因此

  **\[
  \pi(i)=j+1.
  \]**

  由于所有更大的候选均已排除，所以该值一定是最大值。

- 如果 **$s[i]\neq s[j]$**，长度 **$j+1$** 无法成为 **$s[0..i]$** 的相等前后缀。根据性质四，下一个最大的候选长度为

  **\[
  j=\pi(j-1).
  \]**

  因此该回退不会漏掉任何可能的答案。

- 如果最终 **$j=0$**，只需比较 **$s[i]$** 与 **$s[0]$**：
  - 若相等，则 **$\pi(i)=1$**；
  - 若不相等，则不存在非空的相等前后缀，因此 **$\pi(i)=0$**。

所以算法对于每个位置 **$i$** 都能求出最长的相等真前缀与真后缀长度，算法正确。

### 二、代码实现

```c
/* 1 <= haystack.length, needle.length */
char* strstr(char* haystack, char* needle) {
    int m = strlen(needle);
    /* 处理空子串的特殊情况 */
    if (m == 0) return haystack;
    int n = strlen(haystack);

    int* next = (int*)calloc(m, sizeof(int));
    if (next == NULL) return NULL;

    /* 构建next数组 */
    // j 是目前最长前缀的下一个字符索引，也是目前最长前后缀的长度
    for (int i = 1, j = 0; i < m; i++) {
        while (j > 0 && needle[j] != needle[i]) {
            j = next[j - 1];
        }
        if (needle[j] == needle[i]) {
            next[i] = j + 1;
            j++;
        }
        // 如果最后仍不相等则 next[i] = 0，
        // 但由于 calloc 分配的空间默认初始化为 0，所以省略
    }

    /* KMP搜索 */
    // i 是目前最长后缀的下一个字符索引
    // j 是目前最长前缀的下一个字符索引，也是目前最长前后缀的长度，
    // 还是目前待匹配字符的索引
    for (int i = 0, j = 0; i < n; i++) {
        while (j > 0 && haystack[i] != needle[j]) {
            j = next[j - 1];
        }
        if (haystack[i] == needle[j]) {
            if (j == m - 1) {
                free(next);
                return haystack + i - m + 1;
            }
            j++;
        }
    }

    free(next);
    return NULL;
}
```
